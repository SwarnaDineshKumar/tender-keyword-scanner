AI_NOTES
========

Project: Tritorc Tender / Scope-of-Work Keyword Scanner
Author: Swarna Kumar

AI tools were used during development as a coding and problem-solving
assistant.

AI was used for selected implementation tasks, code review, debugging,
technical questions, and documentation. The project was developed
incrementally, with different parts being written, reviewed, modified,
and tested during development. AI was not used to generate the entire
project as one complete solution.


Prompt 1 — Document Extraction
------------------------------

Prompt:

"Help me write a service that extracts text from both PDF and DOCX
files in an Express/Node.js backend. I am using pdf-parse for PDFs
and mammoth for DOCX files."

Use:

Used as assistance for the initial document-extraction service.
The implementation was then integrated into the existing backend and
adjusted to handle the project's supported file types and errors.


Prompt 2 — Keyword Matching Review
-----------------------------------

Prompt:

"Review this keyword matching function. I need case-insensitive
matching and some common variations of engineering terms, but I also
want to avoid false positives caused by matching keywords inside
unrelated words. What should I improve?"

Use:

Used to review and refine the keyword matching logic and identify
edge cases that should be tested.


Prompt 3 — MongoDB Scan History
--------------------------------

Prompt:

"I already have a working tender scanning API. I want to persist
successful scan results in MongoDB Atlas and retrieve recent scan
history through another API endpoint. What would be a clean way to
organize the database connection, service, controller, and route?"

Use:

Used for guidance while adding the scan-history functionality to the
existing application. The resulting approach was adapted to the
project's existing Express structure and requirements.


Additional AI Assistance
------------------------

AI was also used during development for smaller tasks such as:

- Debugging API and routing issues
- Reviewing error handling
- Discussing edge cases
- Improving frontend presentation
- Reviewing project structure
- Preparing project documentation


AI Usage Summary
----------------

AI was used selectively throughout development rather than as a
single end-to-end project generator.

Some implementation pieces were developed with AI assistance, while
other parts were written and refined independently. AI-generated
suggestions and code were reviewed, modified, integrated, and tested
against the project requirements.

The final scanner does not use an AI/LLM at runtime to determine
keyword matches or relevance.

Document extraction, keyword matching, match counting, relevance
scoring, Excel generation, and scan-history handling are implemented
through the application's backend logic.
